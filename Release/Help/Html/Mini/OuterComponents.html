引用的外部组件

一、功能概述

本工具使用的部分重要外部组件，以提供丰富的功能和良好的用户体验。

二、外部组件清单

【IoC组件】‌
Castle.Windsor、Castle.Core：.NET 平台上一个成熟的开源 ‌IoC（控制反转）容器。
Autofac：.NET 平台的开源依赖注入（DI）容器。‌

【日志组件】‌
NLog：.NET 平台的开源日志记录类库

【JSON序列化组件】‌
Newtonsoft.Json：.NET 生态中最流行的第三方 JSON 处理库

【压缩解压组件】‌
SharpZipLib：.NET平台编写的Zip,GZip,Tar和BZip2库。
SharpCompress：纯 C# 编写的开源压缩库‌，主要用于.NET 平台，支持解压 RAR、7Zip、ZIP、TAR、GZip、BZip2、LZIP、ZSTD 等多种格式，也能创建 ZIP、TAR、GZip、BZip2、LZIP 格式的压缩文件。‌‌

【数据库访问组件】‌
MySql.Data：MySQL数据库访问组件
Oracle.ManagedDataAccess：Oracle数据库访问组件
Npgsql：PostgreSQL数据库访问组件
System.Data.SQLite.Core、Stub.System.Data.SQLite.Core.NetFramework：SQLite数据库访问组件
System.Data：Sql Server数据库访问组件

【Excel组件】‌
ClosedXML：.NET 开源类库‌，专门用于在 C# 等 .NET 环境下读取、修改和写入 Excel 2007+ 文件（.xlsx、.xlsm），无需安装 Microsoft Excel 软件即可操作。
NPOI：一个基于 Apache POI 开发的开源 C# 库，‌可在不安装 Microsoft Office 的环境下读写 Excel、Word 等 Office 文档，支持.xls（Excel 97-2003）和.xlsx（Excel 2007+）格式，以及.docx Word 文档。‌‌

【FTP组件】‌
FluentFTP：一个适用于 .NET 和 .NET Standard 的 FTP 和 FTPS 客户端。
SSH.NET：一个专为.NET 平台优化的 Secure Shell (SSH-2) 开源类库‌，提供 SFTP 和 SCP 功能，支持文件上传、下载、目录操作，可显示传输进度。‌‌‌

【文本解析组件】‌
CommonMark.NET：Markdown解析组件

【UI组件】‌
Ookii.Dialogs.WinForms：对话框组件

【个人数据库访问组件】‌
Breezee.AutoSQLExecutor.Core、Breezee.AutoSQLExecutor.Common：自动参数化SQL执行组件
MyPeach.Net：.Net生态下的一个动态SQL转换工具
