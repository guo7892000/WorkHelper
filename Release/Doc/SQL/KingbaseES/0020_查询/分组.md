## 分组

### 字符分组拼接
```
/*KingbaseES下逗号拼接结果并分组*/
select t.pm_id,
	STRING_AGG(t.spec_code , ',') AS spec_code_list,/*PostgreSQL兼容模式*/
	--GROUP_CONCAT(t.spec_code , ',') AS spec_code_list2,/*MySQL兼容模式*/
	LISTAGG(t.spec_code , ',') AS spec_code_list3 /*Oracle兼容模式*/
from ebom_t_model_spec t 
WHERE T.SPEC_TYPE = 'G'
 And T.CNC_END Is NULL
 AND t.pm_id ='PC-0129122'
GROUP BY t.pm_id;
```
