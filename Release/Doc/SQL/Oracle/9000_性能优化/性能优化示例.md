## 性能优化示例
### 真实案例：针对父子零件路线不一致的包中存储过程的调优
【规则简述】：  
1、基础规则：子件的装配路线和父件的制造路线比较。每个零件，只查到第一个不符合的件即可。
2、子件只有制造路线没有装配路线时，不提醒。
3、子件、当前件、父件如果是实体件但没有路线，不做提醒。
4、总、总(装)、总(分)、总(发)默认都是一样的，不需要提醒。比如子件路线是协=总，父件路线是总(分)=总(装)。不需要提醒。
5、针对当前件为协=协、协=协(委)、协(委)=协、协(委)=协(委)：如1级至多4级的所有父件都为虚拟件时，要提醒。
6、向下最多查找2层子件：如子件为虚拟件，还得向下查找；如子件为实体件，符合则跳过，不符合则提醒。
7、向上最多找4层父件：如父件为虚拟件，还得向上查找；如父件为实体件，符合则跳过，不符合则提醒。
    展开所有1级父件，但只针对1级父件为虚拟件展开2级父件，3、4级父件同理。
8、父子在MBOM表中存在才判断。
9、展开的结构SQL临时表中，父子件一样的，只会有一条记录！
10、针对PDM单和PCO的，取的路线都要用最新的（青岛刘明于2026-03-14确认）
11、当前件为无须路线时，要拿其子件和父件进行比较（注：不符合结果中，当前件依然是该无须路线件）。
【要求】：得到结果得在1分钟左右，多了界面会超时，导致显示失败！！   
【实现过程探索】：  
【方案1】：使用物理临时表  
1、先根据会话ID删除计算范围件，再将本次待计算零件写入待计算临时表。  
2、针对计算范围件的共2级子件，先根据会话ID删除向下展开临时表：  
  2.1 先根据计算范围件，计算其1级子件，写入向下展开临时表。  
  2.2 再根据其1级子件，计算其2级子件，并写入向下展开临时表。  
3、针对计算范围件的共4级父件，先根据会话ID删除向上展开临时表：  
  3.1 先根据计算范围件，计算其1级父件，写入向上展开临时表。  
  3.2 针对1级父件，查找其2级父件，写入向上展开临时表。   
  3.3 同理，实现3、4级父件的计算，并写入向上展开临时表。  
4、利用向下和同上的结果及当前件的路线、跟父子件进行比较，得到不符合项。  
问题：因为向上计算父件的零件非常多，如有几十万数据，如果不使用并发写入，那么写1级父件就花了2分多钟。重复计算时，删除之前计算好的向上临时表也花了12秒。  
如采用并发写入，写入速度快了，但出现并发锁表机率也大大增加。因为该计算是很频繁的。所以方案1最终被抛弃了。  

【方案2】：使用WITH语法的SQL临时表（无任何物理临时表）    
使用用WITH语法，从输入参数，计算范围零件，向下展开2层，向上展开4层，计算不符合项，最终结果，用一个渐近式的SQL实现（后一个SQL使用前面的临时表）。  
最终得到结果在1分钟以内，完美解决。但这种方式也有点小问题：因为SQL太长，用PLSQL DEVELOPER在测试环境编译，有时会失败，要多试几次，并且比较耗时（跟数据库配置有关，测试库很慢，但生产环境几秒就好了），需要耐心等待编译成功！！  
另外，在SQL中调用函数实现某列值的转换时，请不要使用SQL方式，那样会比较耗时，最好是使用循环、字符处理那样的操作，那样效率最高！！  
另外，为了方便复制SQL调试，调用包内的方法也增加了包名前缀。  

```
CREATE OR REPLACE Package Body PKG_PARENT_CHILD_COMP Is
  /*
  功能模块：【获取路线】
  功能描述：获取制造路线或装配路线，用于父子路线不一致、柳柳分析
  重点描述：无
  业务规则：
    1、针对-取第一位，针对/取全部。
    2、本算法针对制造路线或装配路线。
  修订历史：
      20260312  新增，针对-取第一位，针对/取第一位。 huangguohui
      20260314  针对/取全部。 huangguohui
  */
  Function F_GET_ROUTEMFG_STR(ac_str In Varchar2 --字符串
                              ) Return Varchar2 DETERMINISTIC
    PARALLEL_ENABLE Is
    PRAGMA UDF;
    lc_result Varchar2(4000);
  Begin
    -- 1.处理 '-'
    If INSTR(ac_str, '-') > 0 Then
      lc_result := SUBSTR(ac_str, 1, INSTR(ac_str, '-') - 1);
    Else
      lc_result := ac_str;
    End If;
    -- 2.相同类型的转换：Q02, Q03, Q04, Q05 -> C07
    If lc_result In ('Q02', 'Q03', 'Q04', 'Q05') Then
      lc_result := 'C07';
    else
      --总(装)-Q02、总(发)-Q03、总(分)-Q04、总(厢)-Q05，统一替换为总
      lc_result := Replace(lc_result, 'Q02', 'C07');
      lc_result := Replace(lc_result, 'Q03', 'C07');
      lc_result := Replace(lc_result, 'Q04', 'C07');
      lc_result := Replace(lc_result, 'Q05', 'C07');
    End If;
  
    Return(lc_result);
  End F_GET_ROUTEMFG_STR;

  /*
  功能模块：【比较路线】
  功能描述：比较路线是否一致
  重点描述：无
  业务规则：1、只要子件的装配路线与父件的制造路线有交集，则返回1，否则返回0。
  修订历史：
      20260314  新增，只要子件的装配路线与父件的制造路线有交集，则返回1，否则返回0。 huangguohui
      20260318  性能优化，改用文本分隔后存入MAP，再通过MAP是否存在来判断返回。 huangguohui
  */
  Function F_COMP_ROUTEMFG(pr_mfg_str  In Varchar2, --父件的制造路线
                           ch_assm_str In Varchar2 --子件的装配路线
                           ) Return Varchar2 DETERMINISTIC
    PARALLEL_ENABLE Is
    PRAGMA UDF;
    lc_result Varchar2(10) := '0';
  
    -- 定义关联数组类型用于存储元素及其计数
    TYPE t_count_map IS TABLE OF PLS_INTEGER INDEX BY VARCHAR2(4000);
  
    l_map1 t_count_map;
    l_map2 t_count_map;
  
    l_token VARCHAR2(4000);
    l_pos   PLS_INTEGER;
    l_start PLS_INTEGER;
    l_len   PLS_INTEGER;
  
    l_key VARCHAR2(4000);
  Begin
  
    --快速失败：如果两个字符串完全相同（包括顺序），直接返回1
    IF pr_mfg_str = ch_assm_str THEN
      RETURN '1';
    END IF;
  
    -- 如果其中一个为空，另一个不为空，则返回0
    IF (pr_mfg_str IS NULL AND ch_assm_str IS NOT NULL) OR
       (pr_mfg_str IS NOT NULL AND ch_assm_str IS NULL) THEN
      RETURN '0';
    END IF;
    --两个同时为空，返回0
    IF pr_mfg_str IS NULL AND ch_assm_str IS NULL THEN
      RETURN '0';
    END IF;
  
    -- 辅助过程：解析字符串并填充计数Map（计数器不作为判断项）
    -- 为了性能，我们将解析逻辑内联或使用本地逻辑，这里为了代码清晰写在一个块里
    -- 解析 pr_mfg_str
    l_start := 1;
    l_len   := LENGTH(pr_mfg_str);
  
    WHILE l_start <= l_len LOOP
      l_pos := INSTR(pr_mfg_str, '/', l_start);
      IF l_pos = 0 THEN
        l_token := SUBSTR(pr_mfg_str, l_start);
        l_start := l_len + 1; -- 结束循环
      ELSE
        l_token := SUBSTR(pr_mfg_str, l_start, l_pos - l_start);
        l_start := l_pos + 1;
      END IF;
    
      -- 计入 Map1
      IF l_map1.EXISTS(l_token) THEN
        l_map1(l_token) := l_map1(l_token) + 1;
      ELSE
        l_map1(l_token) := 1;
      END IF;
    END LOOP;
  
    -- 解析ch_assm_str
    l_start := 1;
    l_len   := LENGTH(ch_assm_str);
  
    WHILE l_start <= l_len LOOP
      l_pos := INSTR(ch_assm_str, '/', l_start);
      IF l_pos = 0 THEN
        l_token := SUBSTR(ch_assm_str, l_start);
        l_start := l_len + 1;
      ELSE
        l_token := SUBSTR(ch_assm_str, l_start, l_pos - l_start);
        l_start := l_pos + 1;
      END IF;
    
      -- 计入 Map2
      IF l_map2.EXISTS(l_token) THEN
        l_map2(l_token) := l_map2(l_token) + 1;
      ELSE
        l_map2(l_token) := 1;
      END IF;
    END LOOP;
  
    -- 遍历其中一个Map，检查另一个Map中是否存对应KEY
    l_key := l_map1.FIRST;
    WHILE l_key IS NOT NULL LOOP
      IF l_map2.EXISTS(l_key) THEN
        RETURN '1'; --包含相同键，返回1
      END IF;
      --下一个记录
      l_key := l_map1.NEXT(l_key);
    END LOOP;
  
    --返回结果
    Return(lc_result);
  End F_COMP_ROUTEMFG;

  /*
  功能模块：【计算零件所有父子件的符合类型】
  功能描述：计算所有父子件的符合类型：
    返回0表示所有符合；返回9表示是遗漏的场景，需要再分析，修正或增加判断；
    返回x,y，其中x(-1、-2)表示返回第x级子件，y(1、2、3、4)表示返回第y级父件。
  重点描述：无
  业务规则：1、只要子件的装配路线与父件的制造路线有交集，则返回1，否则返回0。
  修订历史：
      20260314  新增，只要子件的装配路线与父件的制造路线有交集，则返回1，否则返回0。 huangguohui
      20260319 业务提出新增规则：不管制造路线，只要装配路线包含销，并且这个件挂在整车下，就不需要提醒 huangguohui
      20260320 针对存在于无路线表的零件，即使路线变更表有数据，也要将制造路线和装配路线取成空值。huangguohui
      20260322 将原来2级子件、4级父件各自判断，合并为所有父子件一起判断，即当前件路线为空时，需要取子件路线跟父件比较。huangguohui
  */
  FUNCTION F_CALC_FITFLAG(I_C1_ROUTE_MFG_STR   VARCHAR2, --1级子件制造路线
                          I_C1_ROUTE_ASSEM_STR VARCHAR2, --1级子件装配路线
                          I_C1_NOROUT          NUMBER, --1级子件无须路线标识
                          I_C2_ROUTE_MFG_STR   VARCHAR2, --2级子件制造路线
                          I_C2_ROUTE_ASSEM_STR VARCHAR2, --2级子件装配路线
                          I_ROUTE_MFGSTR       VARCHAR2, --当前件制造路线
                          I_ROUTE_ASSEMSTR     VARCHAR2, --当前件装配路线
                          I_NOROUT             VARCHAR2, --当前件无须路线标识
                          I_P1_ROUTE_MFG_STR   VARCHAR2, --1级父件制造路线
                          I_P1_ROUTE_ASSEM_STR VARCHAR2, --1级父件装配路线
                          I_P1_NOROUT          VARCHAR2, --1级父件无路线标识
                          I_P1_CAR_FLAG        VARCHAR2, --1级父件整车标志
                          I_P2_ROUTE_MFG_STR   VARCHAR2, --2级父件制造路线
                          I_P2_ROUTE_ASSEM_STR VARCHAR2, --2级父件装配路线
                          I_P2_NOROUT          VARCHAR2, --2级父件无路线标识
                          I_P2_CAR_FLAG        VARCHAR2, --2级父件整车标志
                          I_P3_ROUTE_MFG_STR   VARCHAR2, --3级父件制造路线
                          I_P3_ROUTE_ASSEM_STR VARCHAR2, --3级父件装配路线
                          I_P3_NOROUT          VARCHAR2, --3级父件无路线标识
                          I_P3_CAR_FLAG        VARCHAR2, --3级父件整车标志
                          I_P4_ROUTE_MFG_STR   VARCHAR2, --4级父件制造路线
                          I_P4_ROUTE_ASSEM_STR VARCHAR2, --4级父件装配路线
                          I_P4_NOROUT          VARCHAR2, --4级父件无路线标识
                          I_P4_CAR_FLAG        VARCHAR2 --4级父件整车标志
                          ) RETURN VARCHAR2 DETERMINISTIC
    PARALLEL_ENABLE IS
    PRAGMA UDF;
    v_result      VARCHAR2(50);
    c_null        boolean; --当前件制造路线空标识
    c_ASM_null    boolean; --当前件制造路线空标识
    c1_null       boolean; --1级子件制造路线空标识
    c1_ASM_null   boolean;
    c2_null       boolean; --2级子件制造路线空标识
    c2_ASM_null   boolean;
    p1_null       boolean; --1级父件制造路线空标识
    p2_null       boolean;
    p3_null       boolean;
    p4_null       boolean;
    v_assm_c43    varchar2(10); --当前件装配路线包含销标志：0-不包含，1-包含
    v_assm_c43_c1 varchar2(10); --1级子件的装配路线包含销标志：0-不包含，1-包含
    v_assm_c43_c2 varchar2(10); --2级子件的装配路线包含销标志：0-不包含，1-包含
  BEGIN
    --当前件
    c_null     := (I_ROUTE_MFGSTR IS NULL);
    c_ASM_null := (I_ROUTE_ASSEMSTR IS NULL);
    v_assm_c43 := PKG_PARENT_CHILD_COMP.F_COMP_ROUTEMFG('C43',
                                                              I_ROUTE_ASSEMSTR); --当前件装配路线包含销标识
    --子件
    c1_null       := (I_C1_ROUTE_MFG_STR IS NULL);
    c2_null       := (I_C2_ROUTE_MFG_STR IS NULL);
    c1_ASM_null   := (I_C1_ROUTE_ASSEM_STR IS NULL);
    c2_ASM_null   := (I_C2_ROUTE_ASSEM_STR IS NULL);
    v_assm_c43_c1 := PKG_PARENT_CHILD_COMP.F_COMP_ROUTEMFG('C43',
                                                                 I_C1_ROUTE_ASSEM_STR); --1级子件的装配路线包含销标识
    v_assm_c43_c2 := PKG_PARENT_CHILD_COMP.F_COMP_ROUTEMFG('C43',
                                                                 I_C2_ROUTE_ASSEM_STR); --2级子件的装配路线包含销标识
    --父件
    p1_null := (I_P1_ROUTE_MFG_STR IS NULL);
    p2_null := (I_P2_ROUTE_MFG_STR IS NULL);
    p3_null := (I_P3_ROUTE_MFG_STR IS NULL);
    p4_null := (I_P4_ROUTE_MFG_STR IS NULL);
  
    --根据不同值判断属于哪种不符合类型：顺序改变会影响结果，调整时要充分考虑清楚！
    v_result := case
                  when c_null then
                  --1.当前件制造路线为空：最小从-2开始，最大4
                   case
                   --1.0 不需要提醒的（包含不需要判断父件）
                     when I_NOROUT = 0 Then
                      '0' --【当前件非无须路线】未维护路线，不用提醒
                     when c1_null and c2_null Then
                      '0' --【C1空，C2空】不提醒：OK
                     when c1_null and I_C1_NOROUT = 0 Then
                      '0' --【C1空且非无须路线】未维护路线，不用提醒
                     when c1_null = false and c1_ASM_null Then
                      '0' --【C1非空但无装配路线】不用提醒
                     when c1_null and c2_null = false and c2_ASM_null Then
                      '0' --【C2非空但无装配路线】不用提醒
                   --1.1 协协(委)：提醒
                     when I_C2_ROUTE_MFG_STR In ('C10', 'Q19') And
                          I_C2_ROUTE_ASSEM_STR In ('C10', 'Q19') and I_NOROUT = 1 and
                          I_C1_NOROUT = 1 and I_P1_NOROUT = 1 and I_P2_NOROUT = 1 and
                          I_P3_NOROUT = 1 and I_P4_NOROUT = 1 Then
                      '-2,4' --【C1空，C2协协(委)】提醒:OK
                     when I_C1_ROUTE_MFG_STR In ('C10', 'Q19') And
                          I_C1_ROUTE_ASSEM_STR In ('C10', 'Q19') and I_NOROUT = 1 and
                          I_P1_NOROUT = 1 and I_P2_NOROUT = 1 and I_P3_NOROUT = 1 and
                          I_P4_NOROUT = 1 Then
                      '-1,4' --【C1协协(委)】要提醒:OK
                   --1.2 柳柳：不提醒
                     when I_C1_ROUTE_MFG_STR = 'Q31' And
                          I_C1_ROUTE_ASSEM_STR = 'Q31' Then
                      '0' --【C1柳柳】不提醒:OK
                     when c1_null and I_C2_ROUTE_MFG_STR = 'Q31' And
                          I_C2_ROUTE_ASSEM_STR = 'Q31' Then
                      '0' --【C1空，C2柳柳】不提醒:OK
                     when c1_null and c2_null = false and
                          I_P1_ROUTE_MFG_STR = 'Q31' And
                          I_P1_ROUTE_ASSEM_STR = 'Q31' Then
                      '0' --【C1空，P1柳柳】不提醒:OK
                     when c1_null and c2_null = false and
                          I_P2_ROUTE_MFG_STR = 'Q31' And
                          I_P2_ROUTE_ASSEM_STR = 'Q31' And p1_null Then
                      '0' --【C1空，P2柳柳】不提醒:OK
                     when c1_null and c2_null = false and
                          I_P3_ROUTE_MFG_STR = 'Q31' And
                          I_P3_ROUTE_ASSEM_STR = 'Q31' AND p1_null And p2_null Then
                      '0' --【C1空，P3柳柳】不提醒:OK
                     when c1_null and c2_null = false and
                          I_P4_ROUTE_MFG_STR = 'Q31' And
                          I_P4_ROUTE_ASSEM_STR = 'Q31' And p1_null And p2_null And
                          p3_null Then
                      '0' --【C1空，P4柳柳】不提醒:OK
                     when c1_null = false and I_P1_ROUTE_MFG_STR = 'Q31' And
                          I_P1_ROUTE_ASSEM_STR = 'Q31' Then
                      '0' --【C1非空，P1柳柳】不提醒:OK
                     when c1_null = false and I_P2_ROUTE_MFG_STR = 'Q31' And
                          I_P2_ROUTE_ASSEM_STR = 'Q31' And p1_null Then
                      '0' --【C1非空，P2柳柳】不提醒:OK
                     when c1_null = false and I_P3_ROUTE_MFG_STR = 'Q31' And
                          I_P3_ROUTE_ASSEM_STR = 'Q31' AND p1_null And p2_null Then
                      '0' --【C1非空，P3柳柳】不提醒:OK
                     when c1_null = false and I_P4_ROUTE_MFG_STR = 'Q31' And
                          I_P4_ROUTE_ASSEM_STR = 'Q31' And p1_null And p2_null And
                          p3_null Then
                      '0' --【C1非空，P4柳柳】不提醒:OK
                   --1.3 销挂整车：不提醒
                     when v_assm_c43_c1 = '1' And I_P4_CAR_FLAG = '1' And p1_null And
                          p2_null And p3_null then
                      '0' --【C1销，P4整车】；不用提醒
                     when v_assm_c43_c1 = '1' And I_P3_CAR_FLAG = '1' And p1_null And
                          p2_null then
                      '0' --【C1销，P3整车】；不用提醒
                     when v_assm_c43_c1 = '1' And I_P2_CAR_FLAG = '1' And p1_null then
                      '0' --【C1销，P2整车】；不用提醒
                     when v_assm_c43_c1 = '1' And I_P1_CAR_FLAG = '1' Then
                      '0' --【C1销，P1整车】；不用提醒
                     when v_assm_c43_c2 = '1' And I_P4_CAR_FLAG = '1' And p1_null And
                          p2_null And p3_null then
                      '0' --【C2销，P4整车】；不用提醒
                     when v_assm_c43_c2 = '1' And I_P3_CAR_FLAG = '1' And p1_null And
                          p2_null then
                      '0' --【C2销，P3整车】；不用提醒

     本存储过程在测试环境编译会很慢（10分钟左右，但生产环境很快），因为使用太多WITH临时表，记得多试几次！！

  Procedure P_ALL_COMP(i_ConversationId In Varchar2, --业务会话（可选）
                       i_mfgcentercode  In Varchar2, --生产中心（必填）
                       i_cncid          In Varchar2, --PDM变更单号或PCO单流水号
                       i_ItemIDVer      In Varchar2, --展开项目ID及版本（支持逗号分隔多个，每个零件以分号分隔零件号与版本）
                       i_QueryDate      In Varchar2, --查询日期（可选）
                       i_OperatorId     In Varchar2, --当前用户（可选）
                       o_ResData_pc_cur Out Sys_Refcursor, --返回父子不一致结果集
                       o_ResData_ll_cur Out Sys_Refcursor, --返回柳柳结果集
                       o_Return_Code    Out Varchar2, --返回代码

                       o_Sqlerrm        Out Varchar2 --返回存储过程异常
                       ) Is
    v_ConversationId Varchar2(200); --会话ID，如不传入，则生成一个新的GUID
    v_QueryDate      Varchar2(12); --查询日期，如不传入，则取当天
    v_OperatorId     Varchar2(100); --操作人，如不传入，则取admin
  Begin
    o_Return_Code   := pkg_com_define.const_error;
    o_Error_message := pkg_com_define.const_error_message;
    --非必要参数的初始化
    v_ConversationId := nvl(i_ConversationId, sys_guid()); --默认新的GUID
    v_QueryDate      := nvl(i_QueryDate, to_char(sysdate, 'yyyyMMdd')); --默认当天
    v_OperatorId     := nvl(i_OperatorId, 'admin'); --默认admin
    --入参判断

      o_Error_message := '入参生产中心不能为空！';
      return;
    end if;

      o_Error_message := '入参【通知书号】、【零件;版本】至少一项不能为空！';
      return;
    end if;
  
    --1、查询父子路线不一致分析结果
    Open o_ResData_pc_cur FOR
      WITH T_IN_PARA AS /*【输入参数】原始*/
       (SELECT i_cncid as CNCID, /*PDM变更单号：i_cncid*/
               i_mfgcentercode AS MFG_CODE, /*工厂ID：i_mfgcentercode*/

               v_ConversationId AS CONVERSATIONID, /*会话ID*/
               v_QueryDate AS QRY_DATE, /*查询日期*/
               v_OperatorId as OPERATOR_ID, /*操作人*/
               '99999999' AS MAX_DATE_END
          FROM DUAL),
      T_PARAM AS /*【输入参数】增加计算类型*/
       (select A.*,
               CASE

         Where h.cnc_edit = P.CNCID
           And h.ROUTE_MFGSTR Is Not Null),

       (Select A.ITEM_ID, --零件号
               N.VER_NUM, --版本
               P.MFG_CODE,
               P.QRY_DATE
          From EBOM_T_CNCQ_ITEM A
          Join EBOM_T_ITMENGC N
            On A.ITEM_ID = N.ITEM_ID
           And A.VER_NUM_ORIG = N.VER_NUM_ORIG
          JOIN T_PARAM P
            on P.CAL_TYPE = '2'
         Where A.CNC_ID = P.CNCID
           and exists (select 1 --存在于MBOM表的
                  from MBOM_T_MFGITM M
                 where M.MFG_CENTER_CODE = P.MFG_CODE

                   AND M.VER_NUM = N.VER_NUM)),

                  from T_DOWN_1 AA

                select AA.RID, AA.item_pid, AA.item_cid
                  from T_DOWN_2 AA) A /*子件*/
          JOIN T_PARAM P /*参数*/
            ON 1 = 1
          join EBOM_T_ITMENGC CT /*取子件版本：根据8个9获取？？*/
            on A.ITEM_CID = CT.ITEM_ID
           and CT.DATE_END = P.MAX_DATE_END
          LEFT JOIN T_ROUTE R1 /*工艺路线变更临时表*/

      T_DOWN AS /*【子件】：存在于无须路线表时路线取空值*/

                  null
                 else
                  A.ROUTE_ASSEM_STR

               A.ITEM_PID,
               A.ITEM_CID,
               A.VER_NUM_C,
               A.NOROUT_T,
               CASE A.NOROUT_T
                 WHEN 1 then
                  null
                 else
                  A.ROUTE_MFG_STR_S
               end as ROUTE_MFG_STR_S, --原制造路线
               CASE A.NOROUT_T
                 WHEN 1 then
                  null
                 else
                  A.ROUTE_ASSEM_STR_S
               end as ROUTE_ASSEM_STR_S --原装配路线

           AND T.DATE_END > P.QRY_DATE
         WHERE EXISTS (SELECT 1 --结构中的父件存在于MBOM表
                  FROM MBOM_T_MFGITM M
                 WHERE M.MFG_CENTER_CODE = P.MFG_CODE
                   AND M.ITEM_ID = T.ITEM_PID)
           AND EXISTS --前一层的父件存在于无路线表的，才需要展开
         (SELECT 1

       (SELECT T.ROWID AS RID,
               T.ITEM_PID, --父件编号

          JOIN T_UP_2 A
            ON 1 = 1
          JOIN EBOM_T_ENGSTRU T
            ON T.ITEM_CID = A.ITEM_PID --表示向上展开

           AND T.DATE_END > P.QRY_DATE

                  FROM MBOM_T_MFGITM M
                 WHERE M.MFG_CENTER_CODE = P.MFG_CODE
                   AND M.ITEM_ID = T.ITEM_PID)
           AND EXISTS --前一层的父件存在于无路线表的，才需要展开
         (SELECT 1
                  FROM MBOM_T_QDROUTMFGITM W
                 WHERE W.ITEM_ID = A.ITEM_PID
                   AND W.MFG_CENTER_CODE = P.MFG_CODE)),
      T_UP_4 AS /*4级父件*/
       (SELECT T.ROWID AS RID,
               T.ITEM_PID, --父件编号
               T.ITEM_CID --子件编号
          FROM T_PARAM P
          JOIN T_UP_3 A
            ON 1 = 1
          JOIN EBOM_T_ENGSTRU T
            ON T.ITEM_CID = A.ITEM_PID --表示向上展开
           AND T.DATE_BGN <= P.QRY_DATE
           AND T.DATE_END > P.QRY_DATE
         WHERE EXISTS (SELECT 1 --结构中的父件存在于MBOM表
                  FROM MBOM_T_MFGITM M
                 WHERE M.MFG_CENTER_CODE = P.MFG_CODE
                   AND M.ITEM_ID = T.ITEM_PID)
           AND EXISTS --前一层的父件存在于无路线表的，才需要展开
         (SELECT 1
                  FROM MBOM_T_QDROUTMFGITM W
                 WHERE W.ITEM_ID = A.ITEM_PID
                   AND W.MFG_CENTER_CODE = P.MFG_CODE)),
      T_UP_PRE AS /*【向上预处理】计算制造路线、装配路线*/

                select AA.RID, AA.item_pid, AA.item_cid

                     A.ROUTE_MFG_STR

               A.ITEM_CID,
               A.VER_NUM_P,
               A.NOROUT_P,
               case
                 when A.NOROUT_P = 1 then
                  null
                 else
                  A.ROUTE_MFG_STR_S
               end as ROUTE_MFG_STR_S, /*源制造路线*/
               case
                 when A.NOROUT_P = 1 then
                  null
                 else
                  A.ROUTE_ASSEM_STR_S
               end as ROUTE_ASSEM_STR_S /*源装配路线*/

               P4.NOROUT_P as NOROUT_P4,
               P4.ROUTE_MFG_STR as ROUTE_MFG_STR_P4,
               P4.ROUTE_ASSEM_STR as ROUTE_ASSEM_STR_P4,
               P4.CAR_FLAG as CAR_FLAG_P4,
               C1.RID AS ROWID_C1,
               C2.RID AS ROWID_C2,
               P1.RID AS ROWID_P1,
               P2.RID AS ROWID_P2,
               P3.RID AS ROWID_P3,

                                                          I_C1_ROUTE_ASSEM_STR => C1.ROUTE_ASSEM_STR, --1级子件：装配路线

                                                          I_ROUTE_ASSEMSTR     => L.ROUTE_ASSEMSTR, --当前件：

                      A.ITEM_ID_SHOW, --显示的零件号，取父件

        from T_RESULT_PR A

    --2、查询柳柳分析结果：【柳柳分析起点】

             C1.BIZ_DIC_NAME AS ITEM_TYPE_DESC_, --类型（名称）
```
