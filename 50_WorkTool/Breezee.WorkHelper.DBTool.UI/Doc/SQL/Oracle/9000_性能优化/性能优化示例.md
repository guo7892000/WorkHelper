## 性能优化示例
### 真实案例：针对父子零件路线不一致的包中存储过程的调优
规则简述：  
1、针对某个单，找出零件范围，如某零件是虚拟件，还得向下找两层子件直到有实体件。   
2、子件的装配路线跟父件的制造路线要保持一致。其中路线的格式：协-总-委，或协/总/委；针对-只取第一个，针对/全部都要使用，只是包含即可。  
3、针对父件最多向上找4级，针对子件最多向下找2级；向上找遇到实体件就停止，遇到虚拟件得继续查找上一级父件。  
4、更多规则略..  
要求：得到结果得在1分钟左右，多了界面会超时，导致显示失败！！   
实现过程探索：  
方案一：使用物理临时表  
1、先根据会话ID删除计算范围件，再将本次待计算零件写入待计算临时表。  
2、针对计算范围件的共2级子件，先根据会话ID删除向下展开临时表：  
  2.1 先根据计算范围件，计算其1级子件，写入向下展开临时表。  
  2.2 再根据其1级子件，计算其2级子件，并写入向下展开临时表。  
3、针对计算范围件的共4级父件，先根据会话ID删除向上展开临时表：  
  3.1 先根据计算范围件，计算其1级父件，写入向上展开临时表。  
  3.2 针对1级父件，查找其2级父件，写入向上展开临时表。   
  3.3 同理，实现3、4级父件的计算，并写入向上展开临时表。  
4、利用向下和同上的结果及当前件的路线、跟父子件进行比较，得到不符合项。  
问题：因为向上计算父件的零件非常多，如有几十万数据，如果不使用并发写入，那么写1级父件就花了2分多钟。重复计算时，删除之前计算好的向上临时表也花了12秒。  
如采用并发写入，写入速度快了，但出现并发锁表机率也大大增加。因为该计算是很频繁的。所以方案1最终被抛弃了。  

方案一：使用WITH语法的SQL临时表（无任何物理临时表）    
使用用WITH语法，从输入参数，计算范围零件，向下展开2层，向上展开4层，计算不符合项，最终结果，用一个渐近式的SQL实现（后一个SQL使用前面的临时表）。  
最终得到结果在1分钟以内，完美解决。但这种方式也有点小问题：因为SQL太长，有时PLSQL DEVELOPER 编译失败，要多试几次，并且比较耗时（估计跟数据库配置也有关系），需要耐心等待编译成功！！  
另外，在SQL中调用函数实现某列值的转换时，请不要使用SQL方式，那样会比较耗时，最好是使用循环、字符处理那样的操作，那样效率最高！！见以下示例：  

```
Function F_COMP_ROUTEMFG(pr_mfg_str  In Varchar2, --父件的制造路线
                         ch_assm_str In Varchar2 --子件的装配路线
                         ) Return Varchar2 Is
    lc_result Varchar2(10) := '0';
    v_item VARCHAR2(4000);
    v_pos NUMBER;
    v_temp_str VARCHAR2(32767);
  Begin
    --直接查询得到结果：比较慢
    /*Select case
             when count(1) > 0 then
              '1'
             else
              '0'
           end
      into lc_result
      From Table(pkg_com_util.F_GetStrConvertCol(pr_mfg_str, '/')) A
      join Table(pkg_com_util.F_GetStrConvertCol(ch_assm_str, '/')) B
        on A.column_value = B.column_value;*/
    
    -- 如果字符串内容不大，可以避免表函数调用
    lc_result := '0';
    v_temp_str := '/' || ch_assm_str || '/';
    
    -- 遍历第一个字符串的每个元素
    FOR i IN 1..LENGTH(pr_mfg_str) - LENGTH(REPLACE(pr_mfg_str, '/', '')) + 1 LOOP
        v_item := REGEXP_SUBSTR(pr_mfg_str, '[^/]+', 1, i);
        
        -- 直接在第二个字符串中查找
        IF INSTR(v_temp_str, '/' || v_item || '/') > 0 THEN
            lc_result := '1';
            EXIT;
        END IF;
    END LOOP;
    --返回结果
    Return(lc_result);
  End F_COMP_ROUTEMFG;

```
Procedure P_ALL_COMP(i_ConversationId In Varchar2, --业务会话
                       i_mfgcentercode  In Varchar2, --生产中心
                       i_cncid          In Varchar2, --PDM变更单号
                       i_ItemIDVer      In Varchar2, --展开项目ID及版本（支持逗号分隔多个，每个零件以分号分隔）
                       i_QueryDate      In Varchar2, --查询日期
                       i_OperatorId     In Varchar2, --当前用户
                       o_ResData_pc_cur Out Sys_Refcursor, --返回父子不一致结果集
                       o_ResData_ll_cur Out Sys_Refcursor, --返回柳柳结果集
                       o_Return_Code    Out Varchar2, --返回代码
                       o_Error_Message  Out Varchar2, --业务错误信息
                       o_Sqlerrm        Out Varchar2 --存储过程异常
                       ) Is
  Begin
    o_Return_Code   := pkg_com_define.const_error;
    o_Error_message := pkg_com_define.const_error_message;
    --1、查询父子路线不一致分析结果
    Open o_ResData_pc_cur FOR
      WITH T_IN_PARA AS /*输入参数*/
       (SELECT i_ConversationId AS CONVERSATIONID, /*会话ID：i_ConversationId*/
               i_mfgcentercode AS MFG_CODE, /*工厂ID：i_mfgcentercode*/
               i_QueryDate AS QRY_DATE, /*查询日期：i_QueryDate*/
               '99999999' AS MAX_DATE_END,
               i_OperatorId as OPERATOR_ID, /*操作人：i_OperatorId*/
               i_ItemIDVer as ITEM_ID_VER, /*展开项目ID：i_ItemIDVer，（支持逗号分隔多个，每个零件以分号分隔）*/
               i_cncid as CNCID /*PDM变更单号：i_cncid*/
          FROM DUAL),
      T_PARAM AS /*参数*/
       (select A.*,
               CASE
                 WHEN A.ITEM_ID_VER IS NOT NULL THEN
                  '3'
                 WHEN A.CNCID LIKE 'PCO%' THEN
                  '1'
                 ELSE
                  '2'
               END CAL_TYPE /*计算类型：1-PCO，2-PDM，3-按零件计算*/
          from T_IN_PARA A),
      T_ITM_LI_IN AS /*零件版本：入参*/
       (Select substr(column_value, 0, instr(column_value, ';') - 1) as ITEM_ID,
               substr(column_value, instr(column_value, ';') + 1) AS VER_NUM
          From Table(pkg_com_util.F_GetStrConvertCol((select ITEM_ID_VER
                                                       from T_IN_PARA),
                                                     ','))),
      T_ITM_LI AS /*零件版本：计算清单*/
       (Select A.ITEM_ID, --零件号
               A.VER_NUM --版本
          From T_ITM_LI_IN A
          JOIN T_PARAM P
            on P.CAL_TYPE = '3'
         where not exists (select 1 /*忽略无须配置路线的*/
                  From MBOM_T_QDROUTMFGITM W
                 Where W.ITEM_ID = A.ITEM_ID
                   And W.MFG_CENTER_CODE = P.MFG_CODE
                   And W.VER_NUM = A.VER_NUM)
           and exists (select 1 /*存在于MBOM表的*/
                  from MBOM_T_MFGITM M
                 where M.MFG_CENTER_CODE = P.MFG_CODE
                   AND M.ITEM_ID = A.ITEM_ID
                   AND M.VER_NUM = A.VER_NUM)),
      T_PCO_LI as /*PCO：零件列表*/
       (Select h.ITEM_ID, --零件号
               h.VER_NUM --版本
          From mbom_t_qditmroute_his h
          join T_PARAM P
            on P.CAL_TYPE = '1'
           and H.MFG_CENTER_CODE = P.MFG_CODE
          Join ebom_t_itmengc t
            On h.item_id = t.item_id
           And h.ver_num = t.ver_num
         Where h.cnc_edit = P.CNCID
           And h.ROUTE_MFGSTR Is Not Null --跳过无制造路线的
           And Not Exists /*忽略无须配置路线的*/
         (Select 1
                  From MBOM_T_QDROUTMFGITM W
                 Where W.ITEM_ID = t.ITEM_ID
                   And W.MFG_CENTER_CODE = P.MFG_CODE
                   And W.VER_NUM = t.VER_NUM)),
      TMP_PDM As
       ( /*PMD零件明细*/
        Select A.ITEM_ID, --零件号
                N.VER_NUM, --版本
                P.MFG_CODE,
                P.QRY_DATE
          From EBOM_T_CNCQ_ITEM A
          Join EBOM_T_ITMENGC N
            On A.ITEM_ID = N.ITEM_ID
           And A.VER_NUM_ORIG = N.VER_NUM_ORIG
          JOIN T_PARAM P
            on P.CAL_TYPE = '2'
         Where A.CNC_ID = P.CNCID
           and exists (select 1 /*存在于MBOM表的*/
                  from MBOM_T_MFGITM M
                 where M.MFG_CENTER_CODE = P.MFG_CODE
                   and M.ITEM_ID = A.ITEM_ID
                   AND M.VER_NUM = N.VER_NUM)),
      TMP_PDM_OK As
       ( /*PMD正常件*/
        Select A.ITEM_ID, --零件号
                A.VER_NUM, --版本
                A.MFG_CODE,
                A.QRY_DATE
          From TMP_PDM A
         Where Not Exists /*忽略无须配置路线的*/
         (Select 1
                  From MBOM_T_QDROUTMFGITM W
                 Where W.ITEM_ID = A.ITEM_ID
                   And W.MFG_CENTER_CODE = A.MFG_CODE
                   And W.VER_NUM = A.VER_NUM)),
      TMP_PDM_NG /*PMD无路线件*/
       As
       (Select A.ITEM_ID, --零件号
               A.VER_NUM, --版本
               A.MFG_CODE,
               A.QRY_DATE
          From TMP_PDM A
         Where Exists /*存在无须配置路线的*/
         (Select 1
                  From MBOM_T_QDROUTMFGITM W
                 Where W.ITEM_ID = A.ITEM_ID
                   And W.MFG_CENTER_CODE = A.MFG_CODE
                   And W.VER_NUM = A.VER_NUM)),
      TMP_PDM_1_OK /*PMD的无路线件*/
       As
       (Select C.ITEM_CID, --零件号
               E.VER_NUM, --版本
               A.MFG_CODE,
               A.QRY_DATE --生效时间
          From TMP_PDM_NG A /*针对无路线件*/
          Join EBOM_T_ENGSTRU C /*1级子件*/
            On C.ITEM_PID = A.ITEM_ID
           And C.DATE_BGN <= A.QRY_DATE
           And C.DATE_END > A.QRY_DATE
          Join EBOM_T_ITMENGC E /*零件信息*/
            On E.ITEM_ID = C.ITEM_CID
           And E.DATE_END = '99999999'
         Where Not Exists /*忽略无须配置路线的*/
         (Select 1
                  From MBOM_T_QDROUTMFGITM W
                 Where W.ITEM_ID = C.ITEM_CID
                   And W.MFG_CENTER_CODE = A.MFG_CODE
                   And W.VER_NUM = E.VER_NUM)),
      TMP_PDM_1_NG /*PMD的无路线件*/
       As
       (Select C.ITEM_CID, --零件号
               A.VER_NUM, --版本
               A.MFG_CODE,
               A.QRY_DATE --生效时间
          From TMP_PDM_NG A /*针对无路线件*/
          Join EBOM_T_ENGSTRU C /*1级子件*/
            On C.ITEM_PID = A.ITEM_ID
           And C.DATE_BGN <= A.QRY_DATE
           And C.DATE_END > A.QRY_DATE
          Join EBOM_T_ITMENGC E /*零件信息*/
            On E.ITEM_ID = C.ITEM_CID
           And E.DATE_END = '99999999'
         Where Exists /*存在无须配置路线的*/
         (Select 1
                  From MBOM_T_QDROUTMFGITM W
                 Where W.ITEM_ID = C.ITEM_CID
                   And W.MFG_CENTER_CODE = A.MFG_CODE
                   And W.VER_NUM = E.VER_NUM)),
      TMP_PDM_2_OK /*PMD的无路线件*/
       As
       (Select C.ITEM_CID, --零件号
               E.VER_NUM, --版本
               A.MFG_CODE,
               A.QRY_DATE --生效时间
          From TMP_PDM_1_NG A /*针对1级无路线的*/
          Join EBOM_T_ENGSTRU C /*1级子件*/
            On C.ITEM_PID = A.ITEM_CID
           And C.DATE_BGN <= A.QRY_DATE
           And C.DATE_END > A.QRY_DATE
          Join EBOM_T_ITMENGC E /*零件信息*/
            On E.ITEM_ID = C.ITEM_CID
           And E.DATE_END = '99999999'
         Where Not Exists /*忽略无须配置路线的*/
         (Select 1
                  From MBOM_T_QDROUTMFGITM W
                 Where W.ITEM_ID = C.ITEM_CID
                   And W.MFG_CENTER_CODE = A.MFG_CODE
                   And W.VER_NUM = E.VER_NUM)),
      T_PDM_LI as /*PDM：零件列表*/
       (Select A.*
          From TMP_PDM_OK A
        Union all
        Select A.*
          From TMP_PDM_1_OK A
        Union all
        Select A.*
          From TMP_PDM_2_OK A),
      T_FN_LI as /*最终的零件列表：去重*/
       (Select A.ITEM_ID, A.VER_NUM
          From T_PDM_LI A
        Union
        Select A.ITEM_ID, A.VER_NUM
          From T_PCO_LI A
        Union
        Select A.ITEM_ID, A.VER_NUM
          From T_ITM_LI A),
      T_ITEMS AS /*计算的零件范围：都是有制造路线的。路线取最新的*/
       (SELECT sys_guid() as ITEM_TEMP_ID,
               A.ITEM_ID,
               A.VER_NUM,
               PKG_PARENT_CHILD_COMP.F_GET_ROUTEMFG_STR(R1.route_mfgstr) as ROUTE_MFGSTR,
               PKG_PARENT_CHILD_COMP.F_GET_ROUTEMFG_STR(R1.Route_Assemstr) as ROUTE_ASSEMSTR,
               R1.route_mfgstr as ROUTE_MFGSTR_S, /*原制造路线编码*/
               R1.Route_Assemstr as ROUTE_ASSEMSTR_S /*原装配路线编码*/
          FROM T_FN_LI A
          JOIN T_PARAM P
            ON 1 = 1
          JOIN MBOM_T_QDITMROUTE_HIS R1 /*工艺路线变更：有路线的实体件才分析*/
            ON R1.MFG_CENTER_CODE = P.MFG_CODE
           AND R1.ITEM_ID = A.ITEM_ID
           AND R1.VER_NUM = A.VER_NUM
           AND NOT EXISTS (SELECT 1
                  FROM MBOM_T_QDITMROUTE_HIS H
                 WHERE R1.ROUTE_HIS_ID = H.ROUTE_ID)
           and exists (select 1 /*存在于MBOM表的*/
                  from MBOM_T_MFGITM M
                 where M.ITEM_ID = A.ITEM_ID
                   and M.MFG_CENTER_CODE = P.MFG_CODE
                   AND M.VER_NUM = A.VER_NUM)),
      T_LIST AS /*最终计算的零件范围*/
       (select A.*
          FROM T_ITEMS A
         where not exists (select 1
                  FROM T_ITEMS H
                 where H.ROUTE_MFGSTR = 'Q31'
                   and H.ROUTE_ASSEMSTR = 'Q31'
                   and A.ITEM_TEMP_ID = H.ITEM_TEMP_ID)),
      T_DOWN_1 as /*1级子件*/
       (Select t.rowid as RID,
               t.item_pid, --父件编号
               t.item_cid --子件编号
          From T_PARAM P
          join T_LIST a
            on 1 = 1
          join ebom_t_engstru T
            ON t.item_pid = a.item_id --表示向下展开
           And t.date_bgn <= P.QRY_DATE
           And t.date_end > P.QRY_DATE
         where exists (select 1 /*存在于MBOM表的*/
                  from MBOM_T_MFGITM M
                 where M.MFG_CENTER_CODE = P.MFG_CODE --子件存在于MBOM表
                   and M.ITEM_ID = T.ITEM_CID)),
      T_DOWN_2 as /*2级子件*/
       (Select t.rowid as RID,
               t.item_pid, --父件编号
               t.item_cid --子件编号
          From T_PARAM P
          join T_DOWN_1 a
            on 1 = 1
          join ebom_t_engstru T
            ON t.item_pid = a.item_cid --表示向下展开
           And t.date_bgn <= P.QRY_DATE
           And t.date_end > P.QRY_DATE
         where exists (select 1 /*存在于MBOM表的*/
                  from MBOM_T_MFGITM M
                 where M.MFG_CENTER_CODE = P.MFG_CODE --子件存在于MBOM表
                   and M.ITEM_ID = T.ITEM_CID)),
      T_DOWN AS /*子件*/
       (SELECT PKG_PARENT_CHILD_COMP.F_GET_ROUTEMFG_STR(R1.ROUTE_MFGSTR) AS ROUTE_MFG_STR,
               PKG_PARENT_CHILD_COMP.F_GET_ROUTEMFG_STR(R1.ROUTE_ASSEMSTR) AS ROUTE_ASSEM_STR,
               A.RID,
               A.ITEM_PID,
               A.ITEM_CID,
               CT.VER_NUM as VER_NUM_C,
               CASE
                 WHEN (select count(1)
                         from MBOM_T_QDROUTMFGITM B /*无路线表*/
                        where B.ITEM_ID = A.ITEM_CID
                          AND B.MFG_CENTER_CODE = P.MFG_CODE) = 0 THEN
                  0
                 ELSE
                  1
               END AS NOROUT_T,
               R1.ROUTE_MFGSTR AS ROUTE_MFG_STR_S, /*原制造路线*/
               R1.ROUTE_ASSEMSTR AS ROUTE_ASSEM_STR_S /*原装配路线*/
          FROM (select AA.RID, AA.item_pid, AA.item_cid
                  from T_DOWN_1 AA
                union all
                select AA.RID, AA.item_pid, AA.item_cid
                  from T_DOWN_2 AA) A /*子件*/
          JOIN T_PARAM P /*参数*/
            ON 1 = 1
          join EBOM_T_ITMENGC CT /*取子件版本：根据8个9获取？？*/
            on A.ITEM_CID = CT.ITEM_ID
           and CT.DATE_END = P.MAX_DATE_END
          LEFT JOIN MBOM_T_QDITMROUTE_HIS R1 /*工艺路线变更*/
            ON R1.MFG_CENTER_CODE = P.MFG_CODE
           AND R1.ITEM_ID = A.ITEM_CID
           AND R1.VER_NUM = CT.VER_NUM
           AND NOT EXISTS (SELECT 1
                  FROM MBOM_T_QDITMROUTE_HIS H
                 WHERE R1.ROUTE_HIS_ID = H.ROUTE_ID)),
      T_UP_1 AS /*1级父件*/
       (Select t.rowid as RID,
               t.item_pid, --父件编号
               t.item_cid --子件编号
          From T_PARAM P
          join T_LIST a
            on 1 = 1
          join ebom_t_engstru T
            ON t.item_cid = a.item_id --表示向上展开
           And t.date_bgn <= P.QRY_DATE
           And t.date_end > P.QRY_DATE
         where exists (select 1 /*存在于MBOM表的*/
                  from MBOM_T_MFGITM M
                 where M.MFG_CENTER_CODE = P.MFG_CODE --子件存在于MBOM表
                   and M.ITEM_ID = T.ITEM_PID)),
      T_UP_2 AS /*2级父件：只针对1级件的无路线的零件再向上展开*/
       (Select t.rowid as RID,
               t.item_pid, --父件编号
               t.item_cid --子件编号
          From T_PARAM P
          join T_UP_1 a
            on 1 = 1
          join ebom_t_engstru T
            ON t.item_cid = a.item_pid --表示向上展开
           And t.date_bgn <= P.QRY_DATE
           And t.date_end > P.QRY_DATE
         where exists (select 1 /*存在于无路线表*/
                  from MBOM_T_MFGITM M
                 where M.ITEM_ID = t.ITEM_PID
                   and M.MFG_CENTER_CODE = P.MFG_CODE)),
      T_UP_3 AS /*3级父件*/
       (Select t.rowid as RID,
               t.item_pid, --父件编号
               t.item_cid --子件编号
          From T_PARAM P
          join T_UP_2 a
            on 1 = 1
          join ebom_t_engstru T
            ON t.item_cid = a.item_pid --表示向上展开
           And t.date_bgn <= P.QRY_DATE
           And t.date_end > P.QRY_DATE
         where exists (select 1 /*存在于无路线表*/
                  from MBOM_T_MFGITM M
                 where M.ITEM_ID = t.item_pid
                   and M.MFG_CENTER_CODE = P.MFG_CODE)),
      T_UP_4 AS /*4级父件*/
       (Select t.rowid as RID,
               t.item_pid, --父件编号
               t.item_cid --子件编号
          From T_PARAM P
          join T_UP_3 a
            on 1 = 1
          join ebom_t_engstru T
            ON t.item_cid = a.item_pid --表示向上展开
           And t.date_bgn <= P.QRY_DATE
           And t.date_end > P.QRY_DATE
         where exists (select 1 /*存在于无路线表*/
                  from MBOM_T_MFGITM M
                 where M.ITEM_ID = t.item_pid
                   and M.MFG_CENTER_CODE = P.MFG_CODE)),
      T_UP_PRE AS
       (SELECT PKG_PARENT_CHILD_COMP.F_GET_ROUTEMFG_STR(R1.ROUTE_MFGSTR) AS ROUTE_MFG_STR,
               PKG_PARENT_CHILD_COMP.F_GET_ROUTEMFG_STR(R1.ROUTE_ASSEMSTR) AS ROUTE_ASSEM_STR,
               A.RID,
               A.ITEM_PID,
               A.ITEM_CID,
               CT.VER_NUM AS VER_NUM_P,
               CASE
                 WHEN (select count(1)
                         from MBOM_T_QDROUTMFGITM B /*无路线表*/
                        where B.ITEM_ID = A.ITEM_CID
                          AND B.MFG_CENTER_CODE = P.MFG_CODE) = 0 THEN
                  0
                 ELSE
                  1
               END AS NOROUT_P,
               R1.ROUTE_MFGSTR AS ROUTE_MFG_STR_S, /*原制造路线*/
               R1.ROUTE_ASSEMSTR AS ROUTE_ASSEM_STR_S /*原装配路线*/
          FROM (select AA.RID, AA.item_pid, AA.item_cid
                  from T_UP_1 AA
                union
                select AA.RID, AA.item_pid, AA.item_cid
                  from T_UP_2 AA
                union
                select AA.RID, AA.item_pid, AA.item_cid
                  from T_UP_3 AA
                union
                select AA.RID, AA.item_pid, AA.item_cid
                  from T_UP_4 AA) A /*父件表*/
          JOIN T_PARAM P
            ON 1 = 1
          join EBOM_T_ITMENGC CT /*取父件版本：根据8个9获取？？*/
            on A.ITEM_PID = CT.ITEM_ID
           and CT.DATE_END = P.MAX_DATE_END
          LEFT JOIN MBOM_T_QDITMROUTE_HIS R1 /*工艺路线变更*/
            ON R1.MFG_CENTER_CODE = P.MFG_CODE
           AND R1.ITEM_ID = A.ITEM_PID
           AND R1.VER_NUM = CT.VER_NUM
           AND NOT EXISTS (SELECT 1
                  FROM MBOM_T_QDITMROUTE_HIS H
                 WHERE R1.ROUTE_HIS_ID = H.ROUTE_ID)),
      T_UP AS /*向上列表：整车按照总=总分析，其中C07为总*/
       (SELECT case
                 when A.ROUTE_MFG_STR is null and
                      (A.ITEM_PID like 'GPCA%' or A.ITEM_PID like 'GPLT%') THEN
                  'C07'
                 else
                  A.ROUTE_MFG_STR
               end AS ROUTE_MFG_STR,
               case
                 when A.ROUTE_ASSEM_STR is null and
                      (A.ITEM_PID like 'GPCA%' or A.ITEM_PID like 'GPLT%') THEN
                  'C07'
                 else
                  A.ROUTE_ASSEM_STR
               end AS ROUTE_ASSEM_STR,
               A.RID,
               A.ITEM_PID,
               A.ITEM_CID,
               A.VER_NUM_P,
               A.NOROUT_P,
               A.ROUTE_MFG_STR_S,
               A.ROUTE_ASSEM_STR_S
          FROM T_UP_PRE A),
      T_DOWN_ALL AS /*向下所有件*/
       (select L.ITEM_ID,
               L.VER_NUM,
               L.ROUTE_MFGSTR,
               L.ROUTE_ASSEMSTR,
               T1.ITEM_CID as ITEM_CID_T1,
               T1.VER_NUM_C as VER_NUM_T1,
               T1.ROUTE_MFG_STR as ROUTE_MFG_STR_T1,
               T1.ROUTE_ASSEM_STR as ROUTE_ASSEM_STR_T1,
               T1.NOROUT_T as NOROUT_T1,
               T2.ITEM_CID as ITEM_CID_T2,
               T2.VER_NUM_C as VER_NUM_T2,
               T2.ROUTE_MFG_STR as ROUTE_MFG_STR_T2,
               T2.ROUTE_ASSEM_STR as ROUTE_ASSEM_STR_T2,
               T2.NOROUT_T as NOROUT_T2,
               T1.RID AS ROWID_T1,
               T2.RID AS ROWID_T2,
               Case /*注：以下顺序改变会影响结果，调整时要充分考虑清楚。要把不符合的判断放最前面！*/
                 When T1.ROUTE_MFG_STR Is Null And
                      T2.ROUTE_MFG_STR Is not Null and
                      T2.ROUTE_ASSEM_STR is not null and
                      PKG_PARENT_CHILD_COMP.F_COMP_ROUTEMFG(L.ROUTE_MFGSTR,
                                                                  T2.ROUTE_ASSEM_STR) = '0' Then
                  '2' --1级子件制造路线为空，2级子件的装配路线 != 当前件的制造路线
                 When T1.ROUTE_MFG_STR Is not Null and
                      T1.ROUTE_ASSEM_STR is not null and
                      PKG_PARENT_CHILD_COMP.F_COMP_ROUTEMFG(L.ROUTE_MFGSTR,
                                                                  T1.ROUTE_ASSEM_STR) = '0' Then
                  '1' --1级子件的装配路线 != 当前件的制造路线
                 When T1.NOROUT_T = 0 And T1.ROUTE_MFG_STR Is Null Then
                  '0' --无路线表没有该子件，且该子件的制造路线为空，说明还没维护路线，不用提醒
                 When T1.ROUTE_MFG_STR Is Null And T2.ROUTE_MFG_STR Is Null Then
                  '0' --1、2级子件制造路线都为空
                 When T1.ROUTE_MFG_STR Is Not Null And
                      T1.ROUTE_ASSEM_STR Is Null Then
                  '0' --子件只有制造路线没有装配路线时，不提醒
                 When T1.ROUTE_MFG_STR Is Null And
                      T2.ROUTE_MFG_STR Is Not Null And
                      T2.ROUTE_ASSEM_STR Is Null Then
                  '0' --子件只有制造路线没有装配路线时，不提醒
                 When T1.ROUTE_MFG_STR Is Null And T2.ROUTE_MFG_STR = 'Q31' And
                      T2.ROUTE_ASSEM_STR = 'Q31' Then
                  '0' --1级子件制造路线为空，2级子件为柳柳
                 When T1.ROUTE_MFG_STR = 'Q31' And T1.ROUTE_ASSEM_STR = 'Q31' Then
                  '0' --1级子件为柳柳
                 When T1.ROUTE_MFG_STR Is Null And
                      PKG_PARENT_CHILD_COMP.F_COMP_ROUTEMFG(T2.ROUTE_ASSEM_STR,
                                                                  L.ROUTE_MFGSTR) = '1' Then
                  '0' --1级子件制造路线为空，2级子件的装配路线 = 当前件的制造路线
                 When PKG_PARENT_CHILD_COMP.F_COMP_ROUTEMFG(T1.ROUTE_ASSEM_STR,
                                                                  L.ROUTE_MFGSTR) = '1' Then
                  '0' --1级子件的装配路线 = 当前件的制造路线
                 Else
                  '9' --如有9值，说明上述的判断缺失，需要补充
               End As CAL_FLAG /*是否计算标志：1-是，0-否*/
          from T_LIST L
          left join T_DOWN T1 /*1级子件*/
            ON T1.ITEM_PID = L.ITEM_ID
          left join T_DOWN T2 /*2级子件*/
            on T1.ITEM_CID = T2.ITEM_PID),
      T_UP_ALL AS
       (select L.ITEM_ID,
               L.VER_NUM,
               L.ROUTE_MFGSTR,
               L.ROUTE_ASSEMSTR,
               P1.ITEM_PID as ITEM_PID_P1,
               P1.VER_NUM_P as VER_NUM_P1,
               P1.NOROUT_P as NOROUT_P1, /*1级父件的无路线*/
               P1.ROUTE_MFG_STR as ROUTE_MFG_STR_P1,
               P1.ROUTE_ASSEM_STR as ROUTE_ASSEM_STR_P1,
               P2.ITEM_PID as ITEM_PID_P2,
               P2.VER_NUM_P as VER_NUM_P2,
               P2.NOROUT_P as NOROUT_P2,
               P2.ROUTE_MFG_STR as ROUTE_MFG_STR_P2,
               P2.ROUTE_ASSEM_STR as ROUTE_ASSEM_STR_P2,
               P3.ITEM_PID as ITEM_PID_P3,
               P3.VER_NUM_P as VER_NUM_P3,
               P3.NOROUT_P as NOROUT_P3,
               P3.ROUTE_MFG_STR as ROUTE_MFG_STR_P3,
               P3.ROUTE_ASSEM_STR as ROUTE_ASSEM_STR_P3,
               P4.ITEM_PID as ITEM_PID_P4,
               P4.VER_NUM_P as VER_NUM_P4,
               P4.NOROUT_P as NOROUT_P4,
               P4.ROUTE_MFG_STR as ROUTE_MFG_STR_P4,
               P4.ROUTE_ASSEM_STR as ROUTE_ASSEM_STR_P4,
               P1.RID AS ROWID_P1,
               P2.RID AS ROWID_P2,
               P3.RID AS ROWID_P3,
               P4.RID AS ROWID_P4,
               Case /*注：以下顺序改变会影响结果，调整时要充分考虑清楚。要把不符合的判断放最前面！*/
                 When L.ROUTE_MFGSTR In ('C10', 'Q19') And
                      L.ROUTE_ASSEMSTR In ('C10', 'Q19') And
                      P1.ROUTE_MFG_STR Is Null And P2.ROUTE_MFG_STR Is Null And
                      P3.ROUTE_MFG_STR Is Null And P4.ROUTE_MFG_STR Is Null Then
                  '4' --路线协=协或协(委)=协(委)（设置成可配置）；往上找4层的过程中父件都是虚拟件，给出提醒
                 When P1.ROUTE_MFG_STR Is Null And P2.ROUTE_MFG_STR Is Null And
                      P3.ROUTE_MFG_STR Is Null And
                      P4.ROUTE_MFG_STR is not null and
                      PKG_PARENT_CHILD_COMP.F_COMP_ROUTEMFG(P4.ROUTE_MFG_STR,
                                                                  L.ROUTE_ASSEMSTR) = '0' Then
                  '4' --4级父件的制造路线与当前子件的装配路线一致
                 When P1.ROUTE_MFG_STR Is Null And P2.ROUTE_MFG_STR Is Null And
                      P3.ROUTE_MFG_STR is not null and
                      PKG_PARENT_CHILD_COMP.F_COMP_ROUTEMFG(P3.ROUTE_MFG_STR,
                                                                  L.ROUTE_ASSEMSTR) = '0' Then
                  '3' --3级父件的制造路线与当前子件的装配路线一致
                 When P1.ROUTE_MFG_STR Is Null And
                      P2.ROUTE_MFG_STR is not null and
                      PKG_PARENT_CHILD_COMP.F_COMP_ROUTEMFG(P2.ROUTE_MFG_STR,
                                                                  L.ROUTE_ASSEMSTR) = '0' Then
                  '2' --2级父件的制造路线与当前子件的装配路线一致
                 When P1.ROUTE_MFG_STR is not null and
                      L.ROUTE_ASSEMSTR is not null and
                      PKG_PARENT_CHILD_COMP.F_COMP_ROUTEMFG(P1.ROUTE_MFG_STR,
                                                                  L.ROUTE_ASSEMSTR) = '0' Then
                  '1' --1级父件的制造路线与当前子件的装配路线一致
                 When P1.NOROUT_P = 0 And P1.ROUTE_MFG_STR Is Null Then
                  '0' ----无路线表没有该1级父件，且该1级父件的制造路线为空，说明还没维护路线，不用提醒
                 When P1.ROUTE_MFG_STR Is Null And P2.NOROUT_P = 0 And
                      P2.ROUTE_MFG_STR Is Null Then
                  '0' --1级父件的制造路线为空，无路线表没有该2级父件，且该2级父件的制造路线为空，说明还没维护路线，不用提醒
                 When P1.ROUTE_MFG_STR Is Null And P2.ROUTE_MFG_STR Is Null And
                      P3.NOROUT_P = 0 And P3.ROUTE_MFG_STR Is Null Then
                  '0' --1级、2级父件的制造路线为空，无路线表没有该3级父件，且该3级父件的制造路线为空，说明还没维护路线，不用提醒
                 When P1.ROUTE_MFG_STR Is Null And P2.ROUTE_MFG_STR Is Null And
                      P3.ROUTE_MFG_STR Is Null And P4.NOROUT_P = 0 And
                      P4.ROUTE_MFG_STR Is Null Then
                  '0' --1级、2级、3级父件的制造路线为空，无路线表没有该4级父件，且该4级父件的制造路线为空，说明还没维护路线，不用提醒
                 When P1.ROUTE_MFG_STR Is Null And P2.ROUTE_MFG_STR Is Null And
                      P3.ROUTE_MFG_STR Is Null And P4.ROUTE_MFG_STR Is Null Then
                  '0' --所有四级路线都为空
                 When P1.ROUTE_MFG_STR Is Null And P2.ROUTE_MFG_STR Is Null And
                      P3.ROUTE_MFG_STR Is Null And P4.ROUTE_MFG_STR = 'Q31' And
                      P4.ROUTE_ASSEM_STR = 'Q31' Then
                  '0' --1\2\3级子件制造路线为空，4级子件为柳柳
                 When P1.ROUTE_MFG_STR Is Null And P2.ROUTE_MFG_STR Is Null And
                      P3.ROUTE_MFG_STR = 'Q31' And P3.ROUTE_ASSEM_STR = 'Q31' Then
                  '0' --1\2级子件制造路线为空，3级子件为柳柳
                 When P1.ROUTE_MFG_STR Is Null And P2.ROUTE_MFG_STR = 'Q31' And
                      P2.ROUTE_ASSEM_STR = 'Q31' Then
                  '0' --1级子件制造路线为空，2级子件为柳柳
                 When P1.ROUTE_MFG_STR = 'Q31' And P1.ROUTE_ASSEM_STR = 'Q31' Then
                  '0' --1级子件为柳柳
                 When P1.ROUTE_MFG_STR Is Null And P2.ROUTE_MFG_STR Is Null And
                      P3.ROUTE_MFG_STR Is Null And
                      PKG_PARENT_CHILD_COMP.F_COMP_ROUTEMFG(P4.ROUTE_MFG_STR,
                                                                  L.ROUTE_ASSEMSTR) = '1' Then
                  '0' --4级父件的制造路线与当前子件的装配路线一致
                 When P1.ROUTE_MFG_STR Is Null And P2.ROUTE_MFG_STR Is Null And
                      PKG_PARENT_CHILD_COMP.F_COMP_ROUTEMFG(P3.ROUTE_MFG_STR,
                                                                  L.ROUTE_ASSEMSTR) = '1' Then
                  '0' --3级父件的制造路线与当前子件的装配路线一致
                 When P1.ROUTE_MFG_STR Is Null And
                      PKG_PARENT_CHILD_COMP.F_COMP_ROUTEMFG(P2.ROUTE_MFG_STR,
                                                                  L.ROUTE_ASSEMSTR) = '1' Then
                  '0' --2级父件的制造路线与当前子件的装配路线一致
                 When PKG_PARENT_CHILD_COMP.F_COMP_ROUTEMFG(P1.ROUTE_MFG_STR,
                                                                  L.ROUTE_ASSEMSTR) = '1' Then
                  '0' --1级父件的制造路线与当前子件的装配路线一致
                 Else
                  '9' --如有9值，说明上述的判断缺失，需要补充
               End As CAL_FLAG /*是否计算标志：1-是，0-否*/
          from T_LIST L
          left join T_UP P1 /*1级父件*/
            on P1.ITEM_CID = L.ITEM_ID --只针对循环中零件
        --and P1.VER_NUM = r_up.VER_NUM --这里不能加，因为当前记录为父件的版本
          left join T_UP P2 /*2级父件*/
            on P1.ITEM_PID = P2.ITEM_CID
          left join T_UP P3 /*3级父件*/
            on P2.ITEM_PID = P3.ITEM_CID
          left join T_UP P4 /*4级父件*/
            on P3.ITEM_PID = P4.ITEM_CID
         where L.ROUTE_ASSEMSTR is not null /*子件的装配路线非空*/
        ),
      T_RESULT_C as /*比较结果*/
       (select 1 as RE_TYPE,
               A.ITEM_ID,
               A.ITEM_CID_T1 AS ITEM_L1,
               A.ITEM_CID_T2 AS ITEM_L2,
               null as ITEM_L3,
               null as ITEM_L4,
               A.ROWID_T1,
               A.ROWID_T2,
               null as ROWID_T3,
               null as ROWID_T4,
               TO_NUMBER(A.CAL_FLAG) AS CAL_FLAG
          from T_DOWN_ALL A
         where CAL_FLAG != '0'
           and (A.ROWID_T1 is not null OR A.ROWID_T2 is not null) --至少一个子件不为空
        union all
        select 2 as RE_TYPE,
               A.ITEM_ID,
               A.ITEM_PID_P1 AS ITEM_L1,
               A.ITEM_PID_P2 AS ITEM_L2,
               A.ITEM_PID_P3 AS ITEM_L3,
               A.ITEM_PID_P3 AS ITEM_L4,
               A.ROWID_P1,
               A.ROWID_P2,
               A.ROWID_P3,
               A.ROWID_P4,
               TO_NUMBER(A.CAL_FLAG) AS CAL_FLAG
          from T_UP_ALL A
         where CAL_FLAG != '0'),
      T_RESULT_F as
       (select AA.RE_TYPE,
               AA.ITEM_ID,
               AA.ITEM_L1,
               AA.ITEM_L2,
               AA.ITEM_L3,
               AA.ITEM_L4,
               AA.ROWID_T1,
               AA.ROWID_T2,
               AA.ROWID_T3,
               AA.ROWID_T4,
               ROWNUM AS GROUP_ID,
               AA.CAL_FLAG
          from (select A.RE_TYPE,
                       A.ITEM_ID,
                       A.CAL_FLAG,
                       case
                         when CAL_FLAG >= 1 then
                          A.ITEM_L1
                         else
                          null
                       end as ITEM_L1,
                       case
                         when CAL_FLAG >= 2 then
                          A.ITEM_L2
                         else
                          null
                       end as ITEM_L2,
                       case
                         when CAL_FLAG >= 3 then
                          A.ITEM_L3
                         else
                          null
                       end as ITEM_L3,
                       case
                         when CAL_FLAG >= 4 then
                          A.ITEM_L4
                         else
                          null
                       end as ITEM_L4,
                       case
                         when CAL_FLAG >= 1 then
                          A.ROWID_T1
                         else
                          null
                       end as ROWID_T1,
                       case
                         when CAL_FLAG >= 2 then
                          A.ROWID_T2
                         else
                          null
                       end as ROWID_T2,
                       case
                         when CAL_FLAG >= 3 then
                          A.ROWID_T3
                         else
                          null
                       end as ROWID_T3,
                       case
                         when CAL_FLAG >= 4 then
                          A.ROWID_T4
                         else
                          null
                       end as ROWID_T4,
                       row_number() over (PARTITION BY A.ITEM_ID order by A.ITEM_L1) as RNUM /*按计算零件分组*/
                  from T_RESULT_C A) AA
         where AA.RNUM = 1 /*每个有问题的零件，只取一个即可*/
        ),
      T_RESULT_R AS
       (Select T.GROUP_ID, --组号
               T.ITEM_ID,
               null as RID,
               '0' as level_check,
               0 as LEV,
               '当前件' LEVEL_CHECK_DESC,
               T.RE_TYPE,
               T.CAL_FLAG
          From T_RESULT_F T /*当前件*/
         Where T.RE_TYPE = 1
        UNION ALL
        Select T.GROUP_ID, --组号
               null as ITEM_ID,
               T.ROWID_T1,
               '1-1' as level_check,
               1,
               '1级子件',
               T.RE_TYPE,
               T.CAL_FLAG
          From T_RESULT_F T /*当前件*/
         Where T.RE_TYPE = 1
           and T.ROWID_T1 IS NOT NULL
        UNION ALL
        Select T.GROUP_ID, --组号
               null as ITEM_ID,
               T.ROWID_T2,
               '1-2' as level_check,
               2,
               '2级子件',
               T.RE_TYPE,
               T.CAL_FLAG
          From T_RESULT_F T /*当前件*/
         Where T.RE_TYPE = 1
           and T.ROWID_T2 IS NOT NULL
        /*向上*/
        UNION
        Select T.GROUP_ID, --组号
               T.ITEM_ID,
               null as RID,
               '0' as level_check,
               0,
               '当前件',
               T.RE_TYPE,
               T.CAL_FLAG
          From T_RESULT_F T /*当前件*/
         Where T.RE_TYPE = 2
           and T.CAL_FLAG > 0
        UNION ALL
        Select T.GROUP_ID, --组号
               null as ITEM_ID,
               T.ROWID_T1,
               '-1-1' as level_check,
               -1,
               '1级父件',
               T.RE_TYPE,
               T.CAL_FLAG
          From T_RESULT_F T /*当前件*/
         Where T.RE_TYPE = 2
           and T.ROWID_T1 IS NOT NULL
        UNION ALL
        Select T.GROUP_ID, --组号
               null as ITEM_ID,
               T.ROWID_T2,
               '-1-2' as level_check,
               -2,
               '2级父件',
               T.RE_TYPE,
               T.CAL_FLAG
          From T_RESULT_F T /*当前件*/
         Where T.RE_TYPE = 2
           and T.ROWID_T2 IS NOT NULL
        UNION ALL
        Select T.GROUP_ID, --组号
               null as ITEM_ID,
               T.ROWID_T3,
               '-1-3' as level_check,
               -3,
               '3级父件',
               T.RE_TYPE,
               T.CAL_FLAG
          From T_RESULT_F T /*当前件*/
         Where T.RE_TYPE = 2
           and T.ROWID_T3 IS NOT NULL
        UNION ALL
        Select T.GROUP_ID, --组号
               null as ITEM_ID,
               T.ROWID_T4,
               '-1-4' as level_check,
               -4,
               '4级父件',
               T.RE_TYPE,
               T.CAL_FLAG
          From T_RESULT_F T /*当前件*/
         Where T.RE_TYPE = 2
           and T.ROWID_T4 IS NOT NULL),
      T_RESULT_PR AS
       (select A.GROUP_ID, --组号
               A.LEVEL_CHECK_DESC, --级别
               CASE
                 WHEN A.LEV = 0 then
                  A.ITEM_ID
                 when A.LEV > 0 then
                  D.ITEM_CID
                 ELSE
                  U.ITEM_PID
               END as ITEM_ID_SHOW, --零件编号
               CASE
                 WHEN A.LEV = 0 then
                  A.ITEM_ID
                 when A.LEV > 0 then
                  D.ITEM_CID
                 ELSE
                  U.ITEM_CID
               END as ITEM_CID, --子件编号
               CASE
                 WHEN A.LEV = 0 then
                  A.ITEM_ID
                 when A.LEV > 0 then
                  D.ITEM_PID
                 ELSE
                  U.ITEM_PID
               END as ITEM_PID, --父件编号
               CASE
                 WHEN A.LEV = 0 then
                  C.VER_NUM
                 when A.LEV > 0 then
                  D.VER_NUM_C
                 ELSE
                  U.VER_NUM_P
               END as VER_NUM, --版本
               CASE
                 WHEN A.LEV = 0 then
                  C.ROUTE_MFGSTR_S
                 when A.LEV > 0 then
                  D.ROUTE_MFG_STR_S
                 ELSE
                  U.ROUTE_MFG_STR_S
               END as ROUTE_MFG_STR, /*当前制造路线*/
               CASE
                 WHEN A.LEV = 0 then
                  C.ROUTE_ASSEMSTR_S
                 when A.LEV > 0 then
                  D.ROUTE_ASSEM_STR_S
                 ELSE
                  U.ROUTE_ASSEM_STR_S
               END as ROUTE_ASSEM_STR, /*当前装配路线*/
               CASE
                 WHEN A.LEV = 0 then
                  C.ROUTE_MFGSTR
                 when A.LEV > 0 then
                  D.ROUTE_MFG_STR
                 ELSE
                  U.ROUTE_MFG_STR
               END as ROUTE_MFG_STR_C, /*计算时使用的*/
               CASE
                 WHEN A.LEV = 0 then
                  C.ROUTE_ASSEMSTR
                 when A.LEV > 0 then
                  D.ROUTE_ASSEM_STR
                 ELSE
                  U.ROUTE_ASSEM_STR
               END as ROUTE_ASSEM_STR_C, /*计算时使用的*/
               A.LEV,
               A.level_check,
               A.CAL_FLAG,
               A.RID
          from T_RESULT_R A
          left join T_LIST C /*当前件*/
            on A.ITEM_ID = C.ITEM_ID
           AND A.LEV = 0
          left join T_DOWN D /*向下*/
            ON A.RID = D.RID
           AND A.LEV > 0
          left join T_UP U /*向上*/
            ON A.RID = U.RID
           AND A.LEV < 0
         order by A.GROUP_ID, A.LEV)
      Select distinct TO_CHAR(A.GROUP_ID) AS GROUP_ID, --组号
                      A.ITEM_ID_SHOW AS ITEM_GROUP, --对比零件号
                      A.LEVEL_CHECK_DESC, --层级名称
                      TO_CHAR(A.LEV) AS ELEVEL, --层级数
                      A.CAL_FLAG, --计算不符合标志
                      A.ROUTE_MFG_STR_C, /*计算时使用的制造路线*/
                      A.ROUTE_ASSEM_STR_C, /*计算时使用的装配路线*/
                      A.ROUTE_MFG_STR AS ROUTE_MFG_STR, --制造路线（编码）
                      A.ROUTE_ASSEM_STR AS ROUTE_ASSEM_STR, --装配路线（编码）
                      PKG_COM_UTIL.F_GETROUTELABELBYIDEXA(A.ROUTE_MFG_STR) AS ROUTE_MFG_DESC, --制造路线（名称）
                      PKG_COM_UTIL.F_GETROUTELABELBYIDEXA(A.ROUTE_ASSEM_STR) AS ROUTE_ASSEM_DESC, --装配路线（名称）
                      A.ROUTE_MFG_STR || '=' || A.ROUTE_ASSEM_STR AS ROUTE_GROUP, --路线组,格式:制造路线=装配路线
                      PKG_COM_UTIL.F_GETROUTELABELBYIDEXA(A.ROUTE_MFG_STR) || '=' ||
                      PKG_COM_UTIL.F_GETROUTELABELBYIDEXA(A.ROUTE_ASSEM_STR) AS ROUTE_GROUP_DESC, --路线组（名称）
                      A.ITEM_PID, -- 父件
                      A.ITEM_CID, -- 子件
                      A.LEVEL_CHECK, --级别：0：当前件；1：子件：2：父件
                      A.ITEM_ID_SHOW, --显示的零件号，取父件
                      P.MFG_CODE AS MFG_CENTER_CODE, --生产中心
                      P.CONVERSATIONID AS CONVERSATIONID --业务会话ID
        from T_RESULT_PR A
        join T_PARAM P
          ON 1 = 1
       order by A.GROUP_ID, A.LEV;

  Exception
    When Others Then

  END;
